# 🧮 2025 JavaScript Calculator Precourse

### 문자열 내 숫자를 추출해 더하는 계산기

---

## 📋 기능 요구 사항

1. **기본 기능**

   - 입력받은 문자열에서 숫자를 추출해 더한다.
   - 쉼표(`,`) 또는 콜론(`:`)을 구분자로 사용할 수 있다.
     - `""` → `0`
     - `"1,2"` → `3`
     - `"1,2:3"` → `6`

2. **커스텀 구분자 지정 기능**

   - 문자열 앞부분의 `"//"`와 `"\n"` 사이에 위치한 문자를 커스텀 구분자로 사용한다.
     - `"//;\n1;2;3"` → `6`

3. **입력 예외 처리**

   - 잘못된 입력이 들어온 경우 `[ERROR]`로 시작하는 메시지와 함께 `Error`를 발생시킨다.
   - 프로그램 종료 시 `process.exit()`를 사용하지 않는다.
   - 예외 발생 조건:
     - 숫자가 아닌 문자가 포함된 경우
     - 구분자 규칙이 올바르지 않은 경우
     - 음수가 포함된 경우

4. **출력 요구 사항**

   ```bash
   덧셈할 문자열을 입력해주세요.
   1,2:3
   결과 : 6

   ```

### 주의사항

- 프로그램 종료 시 process.exit()를 호출하지 않는다.
- 프로그래밍 요구 사항에서 달리 명시하지 않는 한 파일, 패키지 등의 이름을 바꾸거나 이동하지 않는다.
- 자바스크립트 코드 컨벤션을 지키면서 프로그래밍한다.
  - 기본적으로 JavaScript Style Guide를 원칙으로 한다.
